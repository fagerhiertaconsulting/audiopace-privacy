# Privacy Policy for AudioPace

Last updated: October 2026

AudioPace ("we", "our", or "the extension") is committed to protecting your privacy. This Privacy Policy explains our practices regarding data collection and usage.

### 1. No Collection of Personal Information
AudioPace does not collect, track, transmit, or sell any personal data, browsing history, keystrokes, IP addresses, or viewing habits. 

### 2. Local Media Processing
All audio analysis, silence detection, dynamic playback rate adjustments, and vocal dynamic compression occur strictly locally in your browser via the standard Web Audio API and HTMLMediaElement. No audio streams, video content, or media metadata are recorded, uploaded, or transmitted to any external server.

### 3. Local Storage Usage
AudioPace uses the browser's local storage (`chrome.storage.local`) solely on your device to:
- Persist your personal playback preferences (custom speeds, sensitivity thresholds, profiles).
- Store an anonymous, offline tally of estimated time saved.
- Cache subscription license status.
None of this data leaves your local device.

### 4. Payments and Licensing
AudioPace uses ExtensionPay and Stripe for processing voluntary upgrades to AudioPace Pro. Payment transactions and billing information are handled directly and securely by Stripe in compliance with their security and privacy standards. AudioPace does not have access to, nor does it store, credit card numbers or financial credentials.

### 5. Changes to This Policy
If this Privacy Policy is updated, the revised version will be posted here with an updated date.

### 6. Contact
For any questions regarding this Privacy Policy, please contact the developer via the official Chrome Web Store support page.
